# Hex 的 Lean 4.30.0 兼容副本

本目录用于本项目明确固定的 Lean 4.30.0 与 Mathlib 提交 `c5ea00351c28e24afc9f0f84379aa41082b1188f`。所选上游发布源码使用 Lean 4.35.0-rc3，不能直接在当前工具链构建；因此没有将主工程升级，而是保存来源明确、可检查差异的本地兼容副本。

四个来源仓库和精确提交见 `origins.json`；所有上游版权头与 Apache-2.0 许可证均保留在各子目录。这里的许可证只适用于相应第三方内容，不给本项目或原稿指定许可证。

兼容改动如下，逐文件差异见 `patches/`：

- 将新版本 `ite_eq_left/right`、`dite_eq_left/right` 改写为当前版本的 `if_pos/if_neg`、`dif_pos/dif_neg`。
- 当前核心库尚无上游使用的 `Nat.sqrt`。计算层改用 HexArith 自己已有并已证明上下平方界的 Newton 平方根，避免引入另一份同名自然数平方根。与固定 Mathlib 平方根相等的对应定理移至 Mathlib 桥接层；数学上的平方根取值不变。
- 对两处 `Id` 程序证明显式展开 `bind`，适配当前归约行为；调整筛法证明中已经闭合或仍需反身性的分支。
- Pollard 搜索模块显式导入固定 Mathlib 的列表乘积定义。此兼容版本的完整搜索层因此不再声称完全独立于 Mathlib；素性证书核心和底层算术仍沿用原有证明。
- 战术建议的排版宽度改用 Lean 4.30 的 Options 接口。
- 子库间使用同目录的相对路径，两个需要 Mathlib 的包均固定到本项目提交；各副本的工具链文件固定为 4.30.0。

没有添加数学公理或绕过内核的证明。运行时算术含上游的编译优化及 C 接口；本项目的证书接受事实使用 `decide +kernel`，实际证明依赖另作审计。`HexPrimalityTheory` 的完整主模块在该环境中实际构建通过，包括证书桥接、区间接口及战术模块。

`SOURCES.json` 记录兼容源码和补丁的 SHA-256。运行 `python scripts/check_hex_sources.py` 可检测意外改动。摘要只用于识别版本；证明有效性由 Lean 构建和公理审计确认。

本目录的 `.lake/` 仅为被忽略的构建缓存，不属于交付源码。原始上游检出保留在项目缓存中，没有修改其受管理源码，也没有向上游仓库提交或推送。
